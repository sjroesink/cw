Code walkthroughs

A pull request turned into a page you work through at your own pace: an overview of what the change is made of, and inside each part the steps that explain it, with the code, a diagram and the diff next to the prose.

Asking for one

Point an agent at this site and say what to explain. It reads the instructions here and publishes the result back:

make a code walkthrough of https://github.com/owner/repo/pull/123
on __BASE__

Publishing and updating need an API key. Reading, and finding your way around, do not.
